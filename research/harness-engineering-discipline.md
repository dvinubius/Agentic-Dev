# Harness Engineering

Beyond the context, what is being engineered?

The workflow & setup, with a full understanding of the harness capabilities.

Fundamentally, we treat every failure as signal and empirically discover the best way to **use the harness**.

The harness user has some wiggle room:
- agent instructions (global, per project)
- skills (global, per project)
- configurations (global, per project)
- hooks 
- plugins in some cases (PI)

The harness developers can learn from the community's shared attempts at making best use of the harness's wiggle room.
