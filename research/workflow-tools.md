# Workflow Tools for Agentic Engineering


## Complete Systems

### BMad

[BMad Method](https://github.com/bmad-code-org/bmad-method)

The BMAD (Breakthrough Method for Agile AI-Driven Development) is a powerful framework 
that transforms individual AI coding tools into virtual agile development teams. 

By using **specialized agents** for distinct roles (PM, Architect, Developer, QA), 
it ensures structured, production-ready software development.

Recommended: use planning for greenfield projects, to create a broad plan (global PRD) 
and split that up into viable work chunks. Then work on those w/ M Pocock's grilling 
sessions workflow.

Very tedious & rigorous work, takes a lot of time and tokens.

Good for large projects with high stakes, but feels unproductive for small scale ones.

Planning for a PRD is nice, but can become exhausting.

### OpenSpec

[`openspec`](https://github.com/Fission-AI/openspec)

Focused on **maintaining specs**.

Pretty loaded & opinionated, but seems usable in lean fashion.

Supports the entire workflow:
`proposal ──► specs ──► design ──► tasks ──► implement`

Develop creating durable specs on a per-feature basis.
Support to reverse engineer specs.

→ fluid not rigid
→ iterative not waterfall
→ easy not complex
→ built for brownfield not just greenfield
→ scalable from personal projects to enterprises

### [Beads](https://github.com/gastownhall/beads)

Beads provides a persistent, structured memory for coding agents. It replaces messy markdown plans with a dependency-aware graph, allowing agents to handle long-horizon tasks without losing context.

Useful for letting agent(s) work autonomously on multiple tasks at once. 

Ralphable: "Take what's next".
