# Decisions

Store durable product-implementation or architecture decisions here when the
reason and consequences will matter later.

Recommended filenames:

```text
0001-short-title.md
0002-short-title.md
```

Recommended sections:

- status and date;
- context;
- decision;
- consequences;
- alternatives considered, when useful;
- related specs, tasks, modules, or superseded decisions.

Decision records describe accepted choices. Proposals should be marked clearly.
