# TL;DR on UI Design

On larger projects with many user journey details, best results 
were obtained by working mockups-first. A set of html mockups, 
navigated from an `index.html`, generated either in Claude Design 
or Claude Code.

Requires user journeys and IA to be established first (minimal 
design package).

Mockup generation works best when a desgin system is defined separately, 
matching product direction / identity.
